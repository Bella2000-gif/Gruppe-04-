# Vignettenstudie – Vorschau des Fragebogens

Klickbare Vorschau des vollständigen Fragebogens zur Bachelorarbeit
„Wissenslücke im organisationalen Wandel und KI-gestütztes Wissensmanagement“
(2 × 2-Vignettendesign).

**Diese Seite erhebt keine Daten.** Nichts wird gespeichert oder versendet;
sie dient ausschließlich dazu, Ablauf, Umfang und Wortlaut zu begutachten.

## Was man hier sehen kann

- **Gruppe V1–V4** oben umschalten, oder „Zufall“ für eine zufällige Zuweisung
  wie in der späteren Erhebung. V1 hohe Lücke/ohne Tool, V2 hohe Lücke/mit Tool,
  V3 niedrige Lücke/ohne Tool, V4 niedrige Lücke/mit Tool.
- **Durchklicken** zeigt Seite für Seite die Teilnehmendensicht,
  **Gesamtübersicht** alle Seiten untereinander mit Kennzahlen zu Umfang und Dauer.
- **Regie-Notizen** blenden Quellenangaben, Auswertungsregeln und
  Begründungen ein; ausgeschaltet entspricht die Ansicht exakt der
  Teilnehmendensicht.

Pro Gruppe wird nur das jeweils zugewiesene Szenario angezeigt.

## Als Website veröffentlichen

Die Seite ist eine einzelne HTML-Datei mit einem Bilderordner und braucht
keinen Server-Code. Über GitHub Pages:

1. Im Repository auf **Settings → Pages**.
2. Unter *Build and deployment* als Source **Deploy from a branch** wählen,
   als Branch **main**, als Ordner **/ (root)**, dann **Save**.
3. Nach ein bis zwei Minuten ist die Seite erreichbar unter
   `https://bella2000-gif.github.io/Gruppe-04-/vignette-vorschau/`

Die Seite trägt `noindex`, wird von Suchmaschinen also nicht aufgenommen.
Wer den Link hat, kann sie trotzdem öffnen — ohne Konto und ohne Anmeldung.
